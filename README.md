# PerDash (Personal Dashboard)

PerDash is a lightweight desktop application designed to streamline personal task management and daily productivity. Built using Python and Flet, it offers a clean interface for organizing activities with scheduled timelines, priority tags, and image attachments.

## Key Features

* **Comprehensive Task Management**: Create and organize tasks categorized by priority levels (High, Medium, Low).
* **Precise Scheduling**: Define start and end dates along with specific timeframes for accurate daily planning.
* **Media Support**: Attach and preview reference images directly within individual task entries.
* **Adaptive Interface**: Modern layout designed for readability, supporting both Dark and Light appearance modes.

## Tech Stack

* **Programming Language**: Python 3.14
* **UI Framework**: Flet (Flutter for Python)
* **Application Bundler**: PyInstaller
* **Windows Packager**: Inno Setup

## Installation (Windows)

Pre-compiled standalone installers are available on the Releases page:

1. Download the installer executable from the [Releases Page](https://github.com/steven-zega/PerDash/releases/latest).
2. Run `PerDash_Setup_v1.0.0.exe` and follow the setup wizard.
3. Launch **PerDash** via the Start Menu or Desktop shortcut.
